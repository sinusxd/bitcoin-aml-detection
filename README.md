*Бинарная классификация подозрительных Bitcoin-транзакций (AML) и демонстрационный сервис мониторинга*

---

## О проекте

Финансовые транзакции могут быть связаны как с легальной деятельностью, так и с незаконными операциями, включая
отмывание денежных средств. Мы работаем с публичным датасетом **Elliptic**, содержащим граф транзакций Bitcoin. Каждая
транзакция уже описана 166 предвычисленными признаками, поэтому задачу можно решать преимущественно методами
классического табличного ML.

**Ключевые особенности задачи:**

- сильный дисбаланс классов (illicit ≈ 2%);
- огромная доля неразмеченных объектов (≈ 77%), что открывает простор для semi-supervised подходов;
- данные распределены по 49 временным шагам, поэтому нужен честный **temporal split** и анализ **временного дрейфа**.

## Цель

Разработать модель бинарной классификации подозрительных транзакций и демонстрационный сервис AML-мониторинга, который
по признакам транзакции оценивает вероятность класса **illicit** и объясняет решение.

## Методология

- **Метрики:** PR-AUC, F1 / precision / recall по классу illicit.
- **Валидация:** только temporal split: обучение на ранних шагах, тест на поздних, без утечек из будущего.
- **Модели:** DummyClassifier -> LogReg -> RandomForest -> CatBoost / XGBoost -> MLP (+ GNN).
- **Semi-supervised:** self-training / pseudo-labeling, PU-learning, label propagation по kNN-графу в пространстве
  признаков.
- **Интерпретируемость:** SHAP для топ-факторов по каждой транзакции.

## Ожидаемый результат

- бинарный классификатор подозрительных транзакций;
- сравнение LogReg / RF / CatBoost-XGBoost (+ MLP / табличная DL);
- исследование semi-supervised методов;
- анализ временного дрейфа;
- интерактивный AML-сервис: API, скоринг и объяснения.
